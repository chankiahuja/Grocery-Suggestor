# PantryPal

The active stack is Spring Boot, PostgreSQL and React/TypeScript. See [README](README.md), [agent guidance](AGENTS.md), [environment](docs/ENVIRONMENT.md), and [architecture](docs/ARCHITECTURE.md).

The historical .replit Node workflow is not the startup path for the migrated stack. Use Docker Compose and the React dev command in the README. A Replit host needs Java and the new DB_URL variables configured explicitly.
