# Pantry Pal frontend

Extract the ZIP and open the PantryPal-Frontend folder in VS Code.
Open index.html with Live Server, or run `python -m http.server 8080`
from that folder and visit http://localhost:8080. On Windows, use
`py -m http.server 8080` if needed. No build step is required.

- index.html, landing.css: compact landing page and account actions.
- login.html, signup.html, auth.css, auth.js: passwordless account screens.
- home.html, refinement.css: household dashboard, inventory, shopping list,
  wishlist and sample price comparison.
- theme.css: shared colours and styling.
- SVG and PNG files: logo, icon and household image.

Demo OTP: 123456. Email/SMS delivery and real authentication require a
backend. The dashboard uses sample prices and browser-local data.
